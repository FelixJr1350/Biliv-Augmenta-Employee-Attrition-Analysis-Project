# Biliv-Augmenta-Employee-Attrition-Analysis-Project
This project analyzes employee attrition trends at Biliv-Augmenta to identify key factors influencing turnover and recommend strategies for improving retention.

The following are included in the report file:

Key Insights:

Recent Promotions: Higher attrition among recently promoted employees.

Manager Tenure: Longer manager-employee relationships reduce attrition.

Overtime Impact: Employees working overtime have triple the attrition rate.

Department Trends: Sales, HR, and Technology show the highest attrition.

Business Travel: Frequent travelers are more likely to leave.

Tenure: Longer tenure correlates with higher job satisfaction and lower attrition.

Recommendations:

Stabilize manager assignments to build workplace trust.
Implement support systems (e.g., counseling) for high-attrition departments like Sales.
Regulate overtime and business travel to improve work-life balance.
Introduce incentives like bonuses, awards, and career development programs.

Future Work:

Employee engagement surveys and exit interview analysis.
Work-life balance initiatives and compensation impact studies.


Tools Used: Data visualization tools (e.g., Power BI, Excel).

Objective: Reduce attrition by addressing root causes and fostering a supportive workplace.
